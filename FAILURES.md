# FAILURES.md

Bugs that cost real time. Write the entry **after the fix, while the diagnosis is fresh** —
a week later you'll only remember the fix, which is the least useful part.

The most valuable field is **how you found it**. The fix is usually one line. The hunt is
what transfers to the next bug.
